From IQ Samples to Detections

A stage-by-stage walkthrough of the Agilex 7 wideband multichannel processing benchmark on AGMF039R47B1E1VC (1,305,600 ALMs · 18,960 M20K · 12,300 DSP · HBM2e). Facts marked measured come from Quartus Prime Pro 26.1 calibration compiles on the real device; nothing here is estimated from datasheet arithmetic.

The pipeline at a glance

0 · The data format everything shares

Every sample entering the machine is a complex baseband IQ pair: signed 16-bit I and signed 16-bit Q, interpreted as Q1.15 fixed point (range −1.0 … +0.99997, resolution 2−15). Coefficients and beam weights use the same format. All rounding is round-to-nearest-even and all saturation goes through one shared package (rtl/packages/fxp_pkg.sv) with a bit-identical C++ twin — chosen after measuring that round-half-up injects a coherent +½ LSB-per-tie bias that would accumulate through the FIR, land as false DC energy in FFT bin 0, and pollute the CFAR threshold.

Between blocks, data moves on one canonical ready/valid stream bundle (stream_pkg.sv): payload plus start_of_frame, end_of_frame, stream_id, seq, and user metadata. Two rules are enforced everywhere by assertions: payload is frozen while stalled, and no combinational ready chain may span module boundaries — every boundary has a skid or elastic buffer with a registered ready (this is what lets Quartus retime freely on HyperFlex).

1 · Synthetic ADC sources ingress

In: nothing (self-stimulating) — programmable LFSR noise / DDS tone generators, or direct sample injection from the C++ test harness
Out: 16 antenna streams × 8 complex Q1.15 samples per core clock = 4,096 bits of new IQ per cycle at 450 MHz target

There is no real RF front end — the benchmark is about the fabric. The source block produces deterministic, seedable stimulus so any run is exactly reproducible. In simulation the harness can override it and inject arbitrary IQ scenarios (this is the hook the new synthetic-target / range-Doppler issue builds on).

2 · Per-antenna polyphase FIR banks rtl/pfb

In: per antenna, 8 complex samples/cycle (8 polyphase lanes)
Out: same rate, filtered — 8 complex Q1.15 samples/cycle, frame-aligned for the FFT

Each antenna gets a 16-tap-per-phase polyphase filter bank: the channelizer front end that shapes each FFT bin's response (windowed-sinc prototype, designed and Q1.15-quantized by scripts/generate_coefficients.py). Coefficients live in dual banks: software loads the inactive bank over the config bus, then arms a swap that takes effect only at a frame boundary — an assertion fires if data could ever mix banks mid-frame.

What calibration measured

Measured: the textbook systolic DSP-cascade is a loss here — a complex multiply already consumes the DSP block's internal adder, so there is no free chainout; the adder-tree form is 19% faster (537 vs 450 MHz at 8 lanes) and smaller. Full-scale cost: ≈4,096 DSP blocks (33% of the device) for 16 antennas.

3 · Parallel streaming FFTs rtl/fft

In: per antenna, 8 time-domain complex samples/cycle, continuous frames of 1024
Out: per antenna, 8 frequency-bin complex values/cycle — 1024 bins per frame, with per-stage overflow flags

One independent 1024-point streaming FFT per antenna, built from radix-2² single-path delay-feedback stages — no vendor FFT IP anywhere. Parallelism is a decimation-in-time lane split: P identical smaller SDF cores plus log₂(P) merge butterflies, so scaling from 2 to 8 samples/cycle replicates cores instead of redesigning stages. Each stage applies a fixed conditional right-shift (the scaling schedule) with RNE rounding; twiddle factors are generated once, committed with a digest, and shared bit-exactly by RTL, C++, and Python.

This stage is what turns the fast-time axis into range: after the FFT, "frequency bin" is the range gate a target's beat/delay frequency falls into.

What calibration measured

Measured: with automatic placement the critical path landed inside an M20K hard block (the 16-word delay-feedback line), where retiming cannot reach. Forcing small feedback lines into LUT-RAM bought +32 MHz and freed 8 M20Ks per FFT. Open: best block Fmax so far is 362 MHz vs the 450 MHz target — the exact 6-level failing path is documented and queued for the autonomous timing-closure phase.

4 · Time-frequency history & corner turn rtl/memory

In: per antenna, FFT frames written bin-sequentially (write side, core clock)
Out: on request (bin, frame_offset): one aligned vector containing that bin from all 16 antennas (read side, history clock)

The memory heart of the design: a rotating store of the last HISTORY_FRAMES FFT frames for every antenna, banked so that continuous full-rate writes never collide with reads. The corner turn is the key trick — data is written per-antenna in frequency order but read per-bin across antennas (what the beamformer needs). The bank/address mapping was chosen so both directions are pure bit slices: the transpose costs zero arithmetic. This axis (bin × frame history) is also exactly the data a slow-time Doppler FFT reads, which is how a range-Doppler map falls out of this architecture.

What calibration measured

Measured: M20K boundary registers are absorbed into the hard block for free (removing them costs 98.6 MHz); a 32-bit word can fill at most 80% of an M20K (parity-mode granularity). At the nominal 512-frame depth the full-scale store needs 16,384 M20Ks = 86.4% — above the 80% ceiling — so the parameter freeze will likely pick 384 frames → 64.8% (legal: only the FFT size must be a power of two). A subtle correctness bound was caught by analysis: the readable window is depth−2, not depth−1, because a maximum-offset read could race the slot being published — a bug no test could see.

5 · Frequency-bin alignment network rtl/align

In: possibly skewed/reordered history read responses, tagged (bin, frame, antenna-vector)
Out: the beamformer's exact input beat: 8 bins per cycle × 16-antenna vectors, common frame, bins in order, under backpressure

The marshaling layer between memory and math. It issues 8 bin-read requests per cycle across the banks, collects responses that may arrive skewed, reassembles them keyed by their own (bin, frame) identity (not a tag FIFO — a tag FIFO mislabels everything after the first loss), and detects missing or duplicated samples with counters. Two full implementations exist behind one interface, per the spec's mandated experiment.

What calibration measured

Measured — the architecture shoot-out: the multistage omega/Clos network beats the direct crossbar on every axis at full width: −24.6% ALMs, ≥624 vs 296 MHz, and 76% vs 109% (oversubscribed) peak interconnect demand — the crossbar's critical path is 72% wire delay. ALGN_NET_CLOS is the shipping choice.

6 · Complex beamforming matrix rtl/beamformer

In: per cycle: 8 bins × 16-antenna complex vectors + a 16×16 complex weight matrix (double-banked)
Out: per cycle: 8 bins × 16 beam complex samples, Q1.15 with saturation flags, beam/bin identity in metadata

For every frequency bin, Y[b] = Σₐ X[a]·W[b][a] — 16 simultaneous spatial beams from 16 antennas. Weights are runtime-programmable in double banks with frame-boundary swaps (same discipline as FIR coefficients). Arithmetic: 4-real-multiply complex products (measured better than the 3-mult Karatsuba form on this device — Agilex DSP granularity means 3-mult saves no blocks and pays fabric adders), full-precision pipelined accumulation tree, then one round/saturate at the end (rounding is measured to be the expensive operation, not multiplication).

What calibration measured

Measured: exactly 2 DSP per antenna per dot product, scaling linearly → full-scale beam matrix = 4,096 DSPs (33.3%). Together with the PFB the design sits at 67% DSP utilization before FFT/covariance/CFAR are counted — the 75–90% target is met with real math, not filler logic. Block Fmax 414 MHz today; limiting path (weight-store → beam mux → operand) is named for the closure phase.

7 · Power & covariance processing rtl/covariance

In: beam (or antenna) complex samples per bin
Out: 40-bit integrated power per bin per beam, window-boundary metadata; complex cross-power Rxy for selected pairs

Detection statistics. Power = I² + Q² is accumulated over a register-programmable integration window (with an optional exponential-averaging mode); a cross-power engine computes Rxy = X·conj(Y) for runtime-selected antenna/beam pairs. The 40-bit accumulator format is exact for up to 255 maximum-amplitude samples (derived bound, tested at the 256-sample clamp point), saturating with sticky flags beyond. Conjugation is implemented by operand swap rather than negation, dodging the −32768 negation overflow. Window changes latch only at window boundaries; flush is defined as bit-exact equivalence to a post-reset state.

8 · CFAR detection rtl/cfar

In: integrated power stream, bin-ordered per beam per window
Out: sparse 176-bit self-verifying detection events + one summary beat per frame per beam

Cell-averaging CFAR over frequency bins: for each cell under test, the noise floor is estimated from programmable leading/lagging reference cells (skipping programmable guard cells), and the decision is the division-free exact integer comparison cell·N_ref·2^F > α·Σ(reference) with α in Q8.8. Bins whose window is incomplete (frame edges) are suppressed and counted, never guessed. Every detection event carries the four operands of its own comparison — any downstream consumer can re-verify the decision with integer math, which is exactly what the packet-network tests do.

9 · Event aggregation & packet network rtl/packet

In: 16+ ingress ports: CFAR events, power/covariance summaries, telemetry snapshots, error events
Out: 512-bit-wide packets, routed and arbitrated to egress/memory, in-order per (source, VC, destination)

A multistage on-chip network — not a monolithic crossbar — built from pipelined 4×4 switch stages with per-VC input FIFOs, registered round-robin arbitration, and credit-based flow control closed locally per hop. Four virtual channels keep event classes from blocking each other (a stalled bulk-capture VC cannot starve detection events — tested). Verified for zero loss/duplication under random traffic, hotspot fairness, and VC isolation. Measured: full-scale fabric ≈ 210k ALMs — this block is the deliberate routing-pressure driver, with routing already dominating its critical path (2.8 of 4.0 ns).

10 · DMA / HBM abstract memory interface phase 4/9

In: packetized events + bulk capture records
Out: vendor-neutral request/response memory stream → behavioral model in simulation; HBM2e AXI pseudo-channels on silicon (Phase 9)

The pipeline never talks to vendor IP directly. A clean abstract memory interface is the seam: Verilator sees a behavioral memory model; the device-specific top (benchmark_device_top) will attach generated HBM2e controllers behind the same interface in the final phase, leaving the portable hierarchy untouched.

All crossings use the audited CDC library (Gray-pointer async FIFOs for bulk, two-flop/toggle/ handshake synchronizers for signals) and appear in a machine-generated CDC inventory that fails the build if any crossing is untagged. Resets touch control state and validity only — never wide datapath registers — so HyperFlex retiming stays unconstrained.

How it is verified

  • One parameterized RTL, four sizes. tiny (2 ant, 64-pt FFT) and medium (4 ant, 256-pt) run exhaustive Verilator regressions against a bit-exact C++ reference model (itself validated against NumPy). The full configuration gets smoke tests plus the complete Quartus physical flow — simulation scale and synthesis scale are deliberately decoupled.
  • Bit-exact oracles at every stage — RTL vs C++ vs Python golden vectors, all loading the same coefficient/twiddle/weight files. No tolerances anywhere except explicitly documented ones.
  • Fault injection is mandatory: every block's test suite was proven capable of failing by injecting a real bug (wrong twiddle, swapped bank bits, dropped conjugate…) and watching the oracle catch it.
  • Every PR re-gated independently before merge: lint (zero unwaived warnings — 2 narrow waivers project-wide), multi-seed regressions, register-map drift check, CDC inventory.

What comes out the end

For a scenario with real targets in it: the FFT maps each target's fast-time frequency to a range bin; the history store accumulates that bin across frames, where target motion appears as frame-to-frame phase rotation — the Doppler axis; the beamformer separates targets by angle; integration builds SNR; and CFAR emits a compact, self-verifying event for every bin/beam whose power stands statistically above its local noise — plus telemetry proving nothing was lost along the way. The forthcoming synthetic-target scenario generator (see the range-Doppler issue) closes the loop by injecting known targets and rendering the resulting range-Doppler maps with ground truth overlaid.
